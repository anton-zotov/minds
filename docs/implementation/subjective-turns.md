# Subjective turns and decision inspection

The Playbox now contains one Mind, Marta. Turn 0 is initial state; each received event starts the next subjective turn. Time advancement and failed-call retries stay within the current turn. The public turn-marker contract reserves an `actionRequired` kind for future action requests; no action selection is simulated.

Inspector offers a turn dropdown and previous/next/latest navigation. Historical selection pins the view while live cognition continues. State panels use recorded state at the end of that turn; observations, decision sequence, and timeline entries are restricted to that turn. Raw state contains only knowledge accumulated by that turn. Evidence links can deliberately navigate to the turn that recorded the evidence. Reset clears historical selection. Export includes detached turn markers alongside native recordings.

The underhood sequence lists recorded stages in order: received observation, memory, appraisal, and committed transition. Each stage identifies the runtime or provider/model responsible, with expandable complete data. Appraisal shows exact library input, validated proposal, explanation, and metadata/usage. Successful OpenRouter appraisals also retain the actual request body (prompts, output schema, model/settings) and an allowlisted sanitized completion response. Authentication headers and hidden reasoning are excluded. Completion JSON is parsed, redacted, and reserialized so Unicode-escaped credential echoes cannot survive. Failed appraisals identify unavailable diagnostics explicitly.

Verification: 44 core/host/API tests, 15 Playwright tests, typecheck and production build. No live inference is used. Coverage includes same-time event boundaries, retries, historical state without changing live runtime, pinned history, reset, full input/result visibility, and request/response redaction. The independent two-Mind embedding fixture stays separate from the single-Mind Playbox.

Five refreshed baselines were opened and visually inspected: initial desktop, event/transition desktop, expanded input/results, full narrow workspace, and focused narrow Inspector. Selector labels, selected-turn values, readable data, one-character layout, wrapping, and responsive sequence stages were checked. Only variable run-ID lines are masked in expanded input/result snapshots; cognitive data remains compared.
